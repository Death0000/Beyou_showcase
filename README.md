# beyou — Sahil Khan's Design Portfolio

> A premium interactive portfolio showcasing the work and identity of **Sahil Khan** — Interaction Designer & UI/UX Designer based in Sheffield, UK.

![beyou](./src/Assets/about-profile.jpg)

---

## 🧑‍💼 About

**beyou** is a dark-themed, animated personal portfolio built with React + TypeScript + Vite. It showcases Sahil Khan's design work, research, experience, and professional identity as an Interaction Designer pursuing an **MA in Design (Interaction) at Sheffield Hallam University**.

---

## ✨ Features

- 🎨 **Premium dark UI** with glassmorphism, smooth gradients, and motion design
- ⚡ **Framer Motion & Anime.js** — spring physics, magnetic interactions, 3D tilt cards
- 🖼️ **Dual portrait showcase** (Exhibition & Studio) with animated crossfade switcher
- 📱 **Fully responsive** — mobile, tablet, and desktop optimised
- 🧭 **Multi-page SPA** — Home, About, Research, My Works, Customers, Contact
- 🔗 **Live social links** — LinkedIn, Behance, Email
- 🔖 **Custom favicon & brand icon** with brand identity
- 🌐 **SEO-ready** meta tags and semantic HTML

---

## 🏗️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 19 + TypeScript |
| Build Tool | Vite 6 |
| Styling | Tailwind CSS v4 |
| Animation | Framer Motion + Anime.js v4 |
| Icons | Lucide React |
| UI Utilities | Radix UI, class-variance-authority |

## 🚀 Getting Started

### Prerequisites
- Node.js ≥ 18
- npm ≥ 9

### Install & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
